# Efficient Machine — HTML prototype v0.1

Однофайловый прототип для проверки основного игрового цикла.

## Смысл
Источник слева постоянно выпускает частицы энергии. Приёмник справа считает реальный OUTPUT/sec.
Игрок перестраивает машину и пытается выжать из ограниченного набора модулей максимально возможную производительность.

## Модули
- MIRROR — меняет направление потока; повторный тап вращает зеркало.
- SPLIT — создаёт вторую ветку потока; повторный тап меняет сторону ответвления.
- ×2 — удваивает ценность каждой прошедшей частицы.
- BOOST — ускоряет движение прошедшей частицы.
- ERASE — удаляет модуль и возвращает его в инвентарь.

## Быстрая проверка
1. Ничего не ставь: базовый прямой маршрут выдаёт примерно 1–1.5 энергии/сек.
2. Поставь ×2 на прямую линию между источником и приёмником: OUTPUT должен примерно удвоиться.
3. Поставь SPLIT на прямую линию и зеркалами верни ответвление в приёмник: появится второй поток.
4. Комбинируй ×2, SPLIT, BOOST и зеркала и пытайся побить собственный BEST.
