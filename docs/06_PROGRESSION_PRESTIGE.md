# 06 — Progression and Prestige

## Progression rule

Progression expands the design space.

Bad progression:
- +25% output every level forever.

Good progression:
- more power changes module choices;
- a new splitter changes topology;
- a second source changes routing;
- a second receiver creates allocation decisions;
- a larger grid adds space but also longer paths;
- a buffer introduces synchronization.

## Suggested early unlock cadence

Illustrative only; tune by telemetry.

- Start: TURN + ×2.
- 3–5 min: BOOST.
- 8–12 min: SPLITTER.
- 20–30 min: MERGE.
- 45–90 min: BUFFER.
- Later: first alternate SOURCE/RECEIVER configuration.

## Account progression layers

1. **Contract progress** — immediate goals.
2. **Lab level** — unlocks modules and grid configurations.
3. **Blueprint collection** — saved machine designs.
4. **Prestige Cores** — rare structural upgrades.
5. **Meta-machine** — endgame hierarchy.

## Prestige

Prestige should occur only after the player understands the base machine.

Example:
- reach a major production milestone;
- compress current factory;
- earn several Cores based on meaningful achievements/efficiency;
- reset some local progression;
- choose a structural permanent advantage.

Good Core unlock examples:
- +10 base power capacity;
- second SOURCE option;
- second RECEIVER option;
- one extra blueprint slot;
- larger base grid;
- limited overclock mechanic.

Avoid prestige becoming a mandatory repetitive reset every 10 minutes.

## Infinite scaling

Numbers can grow, but the real long-term scaling comes from nested complexity:

`Machine → Factory → Plant → Complex → Network → Grid → ...`

Each tier should reinterpret completed lower-tier designs as reusable components.
