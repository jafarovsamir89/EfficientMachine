# 14 — Roadmap

Dates are deliberately not committed yet. Progress by proof, not calendar.

## Phase 0 — Concept proof (done/in progress)

- HTML particle machine prototype.
- Validate that modules visibly change output.
- Document product thesis.

**Exit:** the idea is understandable and worth moving to native Android.

## Phase 1 — Android Core Alpha

Build:
- native Compose app;
- deterministic simulation;
- SOURCE/RECEIVER/TURN/BOOST/×2/SPLIT;
- Power Limit;
- live FLOW/VALUE/POWER/OUTPUT;
- placement/rotation/remove/undo;
- 10 curated contracts;
- local save.

**Exit:** 10–15 testers can play without developer explanation and deliberately improve output.

## Phase 2 — Depth Alpha

Add:
- MERGE;
- BUFFER;
- contract families;
- unlock sequence;
- blueprint save/load;
- first offline gain;
- instrumentation.

**Exit:** players redesign old machines after unlocking modules; no single dominant layout.

## Phase 3 — Retention Beta

Add:
- procedural contracts with feasibility checks;
- lab progression;
- first prestige Core prototype;
- daily local seeded challenge;
- polish: haptics, generated effects, sound.

**Exit:** healthy internal D1/D7 signals and repeated voluntary optimization.

## Phase 4 — Soft Launch

Add only what metrics justify:
- Play Billing foundation;
- rewarded ads experiments;
- privacy/consent flows;
- crash/performance monitoring;
- store listing/ASO;
- backend only if leaderboard/cloud features justify cost.

**Exit:** retention and monetization coexist without harming core play.

## Phase 5 — Meta-machine

Prototype compression of completed machines into higher-tier blocks.

**Exit:** higher-tier system creates new optimization rather than merely larger numbers.

## Phase 6 — Scale

Possible:
- global daily challenge;
- replay/share codes;
- cloud sync;
- community blueprints;
- live seasons;
- additional module families.

Never scale content faster than clarity.
